## 🚀 How to Run / View

You can open the website in your browser in any of the following ways:

### Method 1: Direct File Open
Double click `index.html` in file explorer or right click and choose **Open With > Google Chrome / Microsoft Edge / Firefox**.

### Method 2: Local HTTP Server (Python / VS Code Live Server)
In PowerShell inside this project folder:
```powershell
python -m http.server 8080
```
Then visit `http://localhost:8080` in your web browser.

## 🛠️ Easy Customization

- **Change Target Email Address**:
  In `assets/js/main.js`, update line 155 (`mailto:midlaj.aviation@gmail.com`) to your preferred primary email address.
- **Update Social Handles**:
  Links to LinkedIn (`midlaj-m1`) and Instagram (`__.mid_laj._`) are prominently placed in the navbar, hero, about, and contact sections.
- **Add Images / Resume**:
  You can place your headshot photo in `assets/images/` and link it in the hero or about section.
